# URAG Workflow Modes

`scope_and_cost_governor` is active from request intake through completion in
every mode. `lightweight` additionally activates retrieval governance, analysis
objectivity review, and research-memory maintenance. It supports evidence-grounded notes and early,
non-comparative analysis.

`benchmark` activates all seven operational roles. A comparison cannot progress
past precheck with an unresolved material condition mismatch unless the user
records a narrower exploratory decision.

`final_review` follows the operational path, then activates four isolated
critical reviewers only after a main-result or final-submission gate. Their
first verdicts must be based on the same evidence snapshot without peer output.
Aggregation is deterministic; conflicting or blocking results become an explicit
user decision rather than autonomous resolution.
