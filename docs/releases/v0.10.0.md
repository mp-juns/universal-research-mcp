# Universal Research MCP 0.10.0

This release restores index rebuilding for historical research records while
keeping evidence fetch and material-claim gates bound to exact registered
source revisions. It also fixes semantic retrieval locators and documents
the separate Codex startup-hook trust step.

## Historical candidates and evidence

- Records without a source SHA remain searchable as `legacy_candidate_only`.
- Records with a SHA absent from the source registry remain searchable as
  `unregistered_revision`.
- Both classes can be included in lexical and semantic indexes, but evidence
  fetch and material evidence claims remain blocked.
- Exact registered sources still require current-byte and canonical-range
  verification. Registry membership does not certify scientific truth.
- Rebuilding preserves canonical JSONL and historical hashes. Failed staged
  verification leaves the published index unchanged.

## Diagnostics and semantic migration

- Index freshness and evidence health are reported separately. A current,
  intact index can have degraded evidence eligibility.
- `doctor` and `validate` report eligibility counts; `--verbose` adds event,
  source-path, SHA and eligibility diagnostics.
- Local semantic configuration preserves explicit `encoder_dtype` and
  `max_length`; both participate in embedding identity.
- GTE `NewModel` nonpersistent position and rotary buffers are restored after
  meta loading without changing checkpoint weights.
- Semantic passage matches return the full canonical parent evidence locator.
  The ranking chunk range is retained separately in retrieval metadata.

## Codex plugin

The bundled plugin version follows 0.10.0. Its starter prompt now fits the
host's 128-character limit; full permission guidance remains in the stateless
SessionStart hook and workflow instructions.

Installing or enabling the plugin does not trust its hook. Review the exact
hook through Codex `/hooks`, explicitly approve it, and verify a new session
asks for scope before task tools. A changed hook definition requires renewed
review. The hook provides workflow instructions, not an OS security boundary.

## Upgrade

```sh
python -m pip install --upgrade "universal-research-mcp==0.10.0"
# The short install alias pins exactly the same core version:
python -m pip install --upgrade "urmcp==0.10.0"

urmcp index ensure --kind lexical --root ROOT
urmcp semantic build --root ROOT --batch-size 32
urmcp doctor --root ROOT
urmcp validate --root ROOT --verbose
urmcp semantic status --root ROOT
```

Run semantic commands only for a configured semantic store. Back up the store
first and preserve the model's compatible dependencies and complete snapshot,
including files referenced by symlinks. See the
[migration guide](../legacy-retrieval-migration.md).

## Validation

Regression coverage exercises all three source classes in lexical, semantic
and hybrid search, evidence acceptance/rejection, staged publication failure,
canonical-byte preservation, encoder identity and semantic parent locators.
Local checks passed: 389 tests, 31 subtests and 11 expected skips; the
installed-wheel boundary suite passed 123 tests with 11 expected skips.
Static analysis, package metadata and bundled-plugin validation passed.

The release workflow runs Python 3.11–3.13 tests and Linux, macOS and Windows
checks against the same wheel before PyPI Trusted Publishing. The `urmcp`
alias is published after the core distribution is available.

Local recovery records and private project paths are excluded from the release.
