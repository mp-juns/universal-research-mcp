# 1분 워크플로우 — 검색 후보에서 답변 또는 보류까지

**v0.8.5 · 5단계 설명형 시연 · 실제 실행 녹화 아님**

[인터랙티브 워크플로우](demo.html) · [아키텍처 경계](architecture.md) · [README](../README.md)

## 보는 방법

저장소를 내려받았다면 `docs/demo.html`을 브라우저로 연다. GitHub에서 보고
있다면 해당 HTML 파일을 내려받아 연다. 파일 하나로 동작하며 추가 설치,
서버, API 키, 외부 리소스가 필요 없다.

**‘60초 재생’**을 누르면 한 화면의 다섯 단계를 각각 12초씩 강조한다.
일시정지, 이전·다음, 시간 막대로 특정 단계를 살펴볼 수 있다.

이 시연은 동작 원리를 설명하는 텍스트만 사용한다. 실제 검색, 모델 실행,
파일 변경, 승인 발급, 인덱스 생성은 하지 않는다.

## 60초 구성

| 구간 | 단계 | 설명 |
| --- | --- | --- |
| **00–12초** | 후보 검색 | 검색 결과는 아직 근거가 아니라 후보라고 표시한다. |
| **12–24초** | 등록 원문 확인 | 이벤트, 파일, 정확한 줄 범위와 현재 SHA-256을 다시 확인한다. |
| **24–36초** | 근거 적격성 | 무결성·범위·개수를 검사한다. 불일치하면 근거를 차단한다. |
| **36–48초** | 호스트 검토 | 관련성, 자료 간 충돌, 원문 자체의 신뢰도를 검토한다. |
| **48–60초** | 답변 또는 보류 | 충분히 뒷받침되면 답하고, 아니면 근거 부족을 명시한다. |

60초는 시연 페이지의 재생 길이이며 실제 MCP 처리 시간의 측정값이 아니다.

## 실제 구현과 대응하는 부분

| 단계 | 구현 근거 | 시연의 경계 |
| --- | --- | --- |
| 후보 검색 | [`memory_search_candidates`](../universal_research_mcp/server.py) | 순위와 이벤트 내용은 표시하지 않는다. |
| 등록 원문 확인 | [`memory_fetch_evidence`](../universal_research_mcp/server.py) | 등록 범위와 현재 파일 버전 확인만 요약한다. |
| 근거 적격성 | [`evaluate_evidence_eligibility`](../universal_research_mcp/core/claim_gate.py) | 의미·충돌·진실성 검사가 아님을 분리한다. |
| 호스트 검토 | [보안 모델](security.md) | MCP가 자동 판정하는 단계처럼 표시하지 않는다. |
| 답변 또는 보류 | [원본과 파생 뷰](decisions/0001-canonical-authority.md) | 답변 생성 결과나 성능 수치를 시뮬레이션하지 않는다. |

이 워크플로우를 실제 실행 영상, 벤치마크 또는 운영 검증으로 소개하지 않는다.
완료된 실험은 [공개 결과 보고서](../benchmarks/results/README.md)에서 별도로 확인한다.
