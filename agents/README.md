# Agent Operations

이 폴더는 `universal_research_mcp` 전용 운영 기록이다. 기존 연구 프로젝트의 agent 문서와 공유하지 않는다.

| 파일·폴더 | 역할 |
|---|---|
| [`AGENT_RULES.md`](AGENT_RULES.md) | 승인, 읽기 경계, attribution, 검증 규칙 |
| [`TODO.md`](TODO.md) | 현재 이주 작업과 다음 작업 |
| [`WORK_LOG.md`](WORK_LOG.md) | 이 프로젝트의 실행·결정·출처 기록 |
| [`sessions/`](sessions/) | 이후 작업별 상세 세션 기록 |

새 연구 event는 이 프로젝트의 `data/events/`에만 기록한다. 기존 `paper_qwen_intent_classifier/research-events/`에는 기록하지 않는다.
